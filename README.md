# AtCoder Python Solutions

AtCoder（競技プログラミング）における Python3 での解答・学習記録リポジトリです。
データサイエンス業務に必要な「アルゴリズムの理解」「計算量を意識した実装力」の向上を目的としています。

## 現在のステータス
- **AtCoder レート:** 灰（目標: 茶色）
- **使用言語:** Python3 (PyPy3)

## 取り組み内容
- [AtCoder Beginners Selection](https://atcoder.jp/contests/abs)（回答完了）
- ABC（AtCoder Beginner Contest） A / B / C 問題の解き直し・計算量改善

## 意識しているポイント
- $O(N)$ や $O(N \log N)$ などの計算量を意識したコード記述
- 可読性の高い変数名・関数化の徹底
