# CSV 初期分析の自動化

> CSV と課題（何を予測・分析したいか）を渡すと、データクレンジング → 初期統計 → 特徴量エンジニアリング案 → ベースラインモデル → 特徴量を足した初期モデルまで行い、日本語レポートにまとめる。

## 解決したこと

- 新しいデータを受け取るたびに、同じ初期分析を手で繰り返していた
- 分析に慣れていない人にも、傾向と次の一手が伝わる形で残したかった

## 仕組み

- Claude Code の「スキル」として手順を定義し、「この CSV で〇〇を予測したい」と頼むだけで動く
- 出力：図付きのレポート（Markdown と HTML）、交差検証のスコア、特徴量を足して育てられる初期モデルのコード
- 元データと中間ファイルは保存しない（レポートと図だけを残す）

## 技術

Python、pandas、scikit-learn、LightGBM、matplotlib、Claude Code
