# PubMed 論文探索ノートブック

> 検索式の一覧（CSV）を渡すと、PubMed を一括検索してヒット数を記録し、論文とアブストラクトを重複なく集める。Google Colab の無料枠で動く。

## 解決したこと

- 先行研究調査で、検索式を少しずつ変えながら何度も検索し、結果をまとめ直す手間があった

## 仕組み

1. 検索式は無料の AI チャットに作らせる（専用のプロンプトを用意）
2. ノートブックに CSV を読み込ませると、検索式ごとのヒット数・警告を一覧にする
3. 件数が多すぎる検索式は直して再実行し、件数が適切なものから論文を集めて重複を除く
4. 結果は表（xlsx）と Markdown で読める

## 技術

Python、Google Colab、NCBI E-utilities（PubMed の API）
